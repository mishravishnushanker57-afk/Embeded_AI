# How to Use Shifra

This guide explains how to set up Shifra and integrate its AI assistant into a website.

## 1. Requirements

Before starting, make sure you have:

- Node.js and npm installed.
- MongoDB Atlas account or MongoDB instance.
- Google Gemini API key.
- Git installed.

## 2. Clone the Repository

```bash
git clone YOUR_REPOSITORY_URL
cd Shifra
```

## 3. Install Dependencies

Install dependencies separately inside the frontend and backend directories.

```bash
cd backend
npm install
```

```bash
cd ../frontend
npm install
```

## 4. Environment Configuration

Create a `.env` file inside the backend directory.

Configure the environment variables required by your project:

```env
PORT=8000
MONGO_URI=your_mongodb_connection_string
GEMINI_API_KEY=your_gemini_api_key
JWT_SECRET=your_jwt_secret
```

Use the exact variable names expected by your source code.

**Never expose your API keys, database credentials, or JWT secrets publicly.**

## 5. Run the Project

Start the backend:

```bash
cd backend
npm run dev
```

Start the frontend in another terminal:

```bash
cd frontend
npm run dev
```

Open the frontend URL displayed in your terminal.

## 6. Configure Your Assistant

From the Shifra dashboard:

1. Create or configure your assistant.
2. Set its assistant name.
3. Enter your business name and description.
4. Choose the assistant's conversational tone.
5. Configure the available themes.
6. Enable voice assistance if required.
7. Configure website navigation pages and their keywords.
8. Save your assistant configuration.

## 7. Website Navigation Configuration

To enable navigation, configure each page with:

- Page name
- Page path
- Navigation keywords

Example:

```json
{
  "name": "Agencies",
  "path": "/agencies",
  "keywords": [
    "agencies",
    "travel agencies",
    "verified travel agencies"
  ]
}
```

The assistant can then recognize commands such as:

- Take me to agencies.
- Open verified travel agencies.
- Show me travel agencies.

The target website must support the configured navigation paths and the integration must handle navigation actions.

## 8. Embedding Shifra

Use the embed script generated by your Shifra dashboard.

Example format:

```html
<script
  src="YOUR_SHIFRA_WIDGET_URL"
  data-widget-id="YOUR_WIDGET_ID">
</script>
```

Replace the placeholders with the actual script URL and widget ID provided by your deployment.

Add the script to your website's HTML.

**Note:** The hosted widget URL and public backend URL must be configured before external websites can use Shifra.

## 9. Troubleshooting

- **Backend connection error:** Check whether the backend server is running.
- **Database connection error:** Verify your MongoDB connection string.
- **AI response error:** Check your Gemini API key and usage limits.
- **Navigation not working:** Verify page names, paths, keywords, and navigation settings.
- **Widget not loading:** Verify the script URL, widget ID, and browser console.

## 10. Security

- Never commit `.env` files.
- Never expose private API keys.
- Validate incoming requests.
- Configure appropriate CORS policies.
- Protect authenticated API routes.
