# Shifra 🤖
### Your AI Assistant, Anywhere.

Shifra is an embeddable AI voice assistant that helps businesses integrate intelligent conversational assistance into their websites.

With Shifra, website owners can create customized AI assistants that understand their business, answer user queries, and navigate visitors to relevant pages.

## ✨ Features

- **AI-Powered Conversations:** Get intelligent responses using Google's Gemini API.
- **Voice Assistance:** Enable voice-based interactions.
- **Customizable Widget:** Configure themes, assistant names, and conversational tones.
- **Website Navigation:** Navigate visitors to specific website pages through natural language commands.
- **Business-Aware Responses:** Customize the assistant using your business information.
- **Embeddable Integration:** Add Shifra to a website using a script tag.
- **Subscription Management:** Supports Free and Pro plan functionality.

## 🚀 Getting Started

1. Clone this repository.
2. Install the frontend and backend dependencies.
3. Configure your environment variables.
4. Start the backend and frontend servers.
5. Configure your AI assistant from the dashboard.

See [HOW_TO_USE.md](HOW_TO_USE.md) for detailed instructions.

## 🔌 Integration

Shifra is designed to be integrated into external websites through an embeddable JavaScript widget.
